AI Engineering Tooling

Agentic coding tools are daily practice, not an add-on — they are how I deliver multi-stack products at team scope on my own.

  • Claude Code (Anthropic) — run agentic sessions end to end: CLAUDE.md project memory, custom skills and slash commands, subagents for parallel exploration and code review, MCP servers connecting the agent to project tooling, and plan mode before large refactors.
  • OpenAI Codex — delegate scoped, well-specified tasks to a sandboxed agent; used for second-opinion review, test generation and repetitive migration work across a codebase.
  • Authored five production Claude Code Skills — packaged my own ML engineering discipline into reusable agent workflows, each enforcing what may and may not be claimed about a model:
    • japano-fit-trainer — end-to-end LoRA fine-tuning workflow for FLUX.2 Klein: dataset provenance and licensing, credential hygiene, VRAM-budgeted pilot runs, resumable training, and a hard rule that “fine-tuned” may only be claimed with a licensed dataset, a training log, a checkpoint, validation images from it and a baseline benchmark — otherwise the status stays MODEL_NOT_TRAINED.
    • japano-motion-trainer — temporal LoRA for Wan2.1 One-to-All Animation: conditioning contract, per-frame identity and garment-consistency gates, joint identity/garment/source-video dataset splits and video licensing rules.
    • japano-body-measurement — calibrated anthropometric regression from a single image, returning evidence-bearing confidence intervals instead of false precision, with out-of-distribution rejection and named regression cases.
    • japano-gpu-performance — cold and warm P50/P90 latency budgets across every pipeline stage, VRAM ceilings, model warm-up, caching and GPU arbitration, with a rule that inference-only time is never reported as total latency.
    • img2threejs — image-to-procedural-Three.js reconstruction through a staged sculpt pipeline and an AI-vision self-correction loop; published Apache-2.0.
  • Working method — specification first, then generation, then verification. Every generated change is read, run and tested before it lands; AI output is treated as a draft to challenge, never a result to trust.
